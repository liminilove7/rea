ImGui 修改器
界面、功能架构与实现说明

把已有攻速实验工具迁移到独立的 ImGui 桌面窗口。保持原攻速事务与校验逻辑，共享原源码；移动速度和怪物识别建立界面与快照契约，等待后续验证的数据源。

Windows x64.NET 8ImGui.NET 1.89.2D3D11 / SDL2

本版可用：原攻速实验入口、只读检查、会话监视、还原和日志。
本版预留：移速倍率草案、怪物列表布局和数据接口；没有对应的实时读取或写入实现。
本次未验证：游戏内实际动画、命中频率、移动效果和怪物识别。离线通过不能替代游戏验收。

03 / 保留的攻速行为

  1. 刷新仅发现指定路径的候选进程；只读检查不写入。
  2. 开始时重新验证进程创建时间、实际路径、模块路径与 SHA256、角色对象和研究基线。
  3. 范围仍为 700–1200；三个原字段按既有宽度仅应用一次，逐项回读并记录。
  4. 活动期间每 500 ms 复核；外部更新或对象改变触发停止，不反复锁定。
  5. 手动停止、60 秒到期、正常关闭、渲染异常退出均尝试通过原事务还原。仅恢复仍为本事务目标值的字段，保留外部值。
  6. 释放过程异常也呈现在状态和记录中；强杀、断电与对象重建无法保证恢复。

原 WinForms 构建仍保留；两个版本使用同一个单实例互斥体，避免并行实验。新版本的运行时从 .NET Framework 切换到 .NET 8，因此既验证原版，也验证同源核心在新运行时下的行为。

04 / 后续功能接入契约

模块已定义数据尚需研究与验证
移动速度MovementSnapshot：可空速度、单位、Evidence。Observation 带 Unavailable / Ready / Stale 及原因。字段语义、数据类型、覆盖写入者、对象生命周期、测量单位、原值恢复与服务器实际位移。没有预先开放写入接口。
怪物识别MonsterSnapshot：ID、名称、分类、可空位置/距离/生命比例、Evidence。IMonsterSource 只读。实体分类证据、身份与复用规则、快照一致性、数量上限、过期与注销处理。先离线夹具再自控环境验证。
来源与版本Source、CapturedAt、BuildIdentity。未来适配器必须校验版本适用性；过期数据明确标记 Stale；不能跨构建自动继承地址。

本版不提供“填写任意地址后立即生效”的通用写内存入口。当前预留页的应用按钮禁用。后续实现必须先确定字段含义和恢复条件，不能只依据 CE 地址颜色或可写性认定修改有效。

验证已完成范围限制
旧核心 / 新运行时两个构建各通过 18 项进程内原生内存夹具检查。合成角色布局；未连接游戏。
新会话控制10 项检查：无目标、重复开始、超时、校验失败、还原异常、关闭释放、日志上限、预留数据与 JSON。模拟会话不代表操作系统异常的全部情况。
ImGui 渲染四个页面通过模拟点击切换；D3D11 离屏画面可读；检查中文字形存在和非空画面。系统捕获超时，之后用户按 Escape 停止桌面自动化；未完成系统鼠标、多 DPI 和显卡兼容性验收。

结果位于 verification。历史原版 JSON 保持原样。截图为自身离屏渲染结果，不截取其他窗口。首次发现的问号问题来自默认字体没有替换，已改为清空默认字体集后加载微软雅黑，并加入中文字形验证。自包含发布包已成功构建；随后执行发布包复测的合并命令被自动审批拦截，未取得发布包独立运行复测结果。

06 / 回家后的验证顺序

  1. 先运行 preview.cmd，确认中文、四个页面与本机显示缩放；关闭后再启动常规模式。
  2. 核对游戏根目录与版本。当前 Profile 仍为 D:\Workspace\AION_TW\DeuLuncher\bin56\aion.bin，路径不同会找不到目标；不能为了连接而移除模块版本校验。
  3. 在自己可控制的测试环境先做只读检查，核实对象、基线与模块身份。失败时保留原因。
  4. 对既有攻速功能记录修改前、实验中和还原后的动画周期、实际命中时间与服务端结果；不要把客户端字段变化直接写成攻速已生效。
  5. 检查日志与还原回读，并验证正常停止与角色状态变化。出现未解决项后先恢复环境再重试。
  6. 移动和怪物功能先整理版本身份、数据语义与离线样本，再实现对应适配器。本版预留界面不会自动启用。
